Click the buttons below to test different notification types

Features:

  • ✅ Auto-dismiss with countdown progress bar
  • ✅ Smooth slide-in/out animations
  • ✅ Multiple toasts can stack vertically
  • ✅ Manual close button (X)
  • ✅ Dark mode support
  • ✅ Responsive design

Usage in Controllers:

// Success
return redirect()->back()->with('success', 'Data saved!');

// Error
return redirect()->back()->with('error', 'Failed to save!');

// Warning
return redirect()->back()->with('warning', 'Be careful!');

// Info
return redirect()->back()->with('info', 'Processing...');
